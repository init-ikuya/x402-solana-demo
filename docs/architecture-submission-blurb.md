# Architecture submission blurb

This x402 demo on Solana connects an AI agent, TypeScript gateway, local facilitator, and custom Anchor program through an experimental auth-capture escrow binding: the payer funds a bounded hold before the API runs, then the merchant captures the actual charge and releases the remainder atomically. LiteSVM and simulated-RPC HTTP tests cover the local hold, capture, release, refund, and payer reclaim rules; live Devnet balances and the generic direct-charge authorization flow remain unverified. The wider project also includes exact, upto, and a repository-backed Anchor batch-settlement route; the payment-channels Issue #90 Closing proposal is separate.
